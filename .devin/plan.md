# 计划：《思考，快与慢》解说稿 → 头条号发布（练手+占坑）

> 原始诉求：发一部读物的读后感/解说到内容平台，练手验证「蒸馏→适配→发布」全流程

## 1. 预期效果

产出《思考，快与慢》（Thinking, Fast and Slow 英文版）的小A式解说稿一套：蒸馏笔记 + 5~7 集讲稿（每集纯汉字 1500~2000）+ 完整版 + 头条号发布适配包；用户注册头条号后日更连载发布，第 1 集读者端可见即闭环。关键约束：版权书无可提取的合法全文 → 走模式B（凭知识 + 四档存疑清单）；发布动作由用户完成，agent 负责备好稿子和指引。

## 2. 方案与结论

- **平台选型**：番茄小说被淘汰（未签约作品读者不可见；签约评估是小说指标：题材/人设/主线/代入感，非虚构解说稿不匹配；短故事要求情节完整的故事体）。选中头条号：字节系、图文直发无签约门槛、练手无成本。备选不启用：知乎/豆瓣/公众号（随时可加发）。
- **原文获取**：Internet Archive 有受控借阅馆藏（`thinkingfastslow0000kahn`，2011 FSG 版 499 页），但借阅件为 LCP/ACS 加密无法提取文本；其他"免费电子书站"均为盗版源，不采用 → 定模式B。本书是被解读最多的非虚构之一（38章结构、Linda问题/锚定转盘/91%出租车/结肠镜峰终实验均公共高讨论度），模式B保真够用；例外通道：用户日后合法获得 DRM-free 文件丢入 `books/` 即升级模式A。
- **内容形态**：头条图文甜点区 1500~3000 字，分集稿天然适合日更连载；每集配头条式标题 + ~100字摘要 + 话题标签。
- **语言桥接**：英文书 → 中文讲稿；术语建中英对照表，正文全中文 + 本土化类比（skill 的本土化映射规则正对口）。

## 3. 具体执行操作

1. **蒸馏笔记** —— `output/《思考，快与慢》/00-蒸馏笔记.md`
   - 执行内容：全书问题定位；核心论点 5~7 个写成四段式（结论/原理/步骤/边界）；论证链+保留案例（Linda问题、锚定转盘、Tom W、91%出租车贝叶斯题、结肠镜峰终实验等）；卡尼曼生平与特沃斯基合作史（诺奖背景）；争议点（专家直觉之争：卡尼曼 vs Klein 有效环境论）；误读陷阱（系统1≠"低级脑"、损失厌恶≠"别冒险"）；中英术语对照表（System 1/2、WYSIATI、anchoring、prospect theory、peak-end rule、experiencing/remembering self）；未覆盖清单；四档存疑清单
   - 依赖：无
2. **分集大纲** —— `output/《思考，快与慢》/01-大纲.md`
   - 执行内容：5~7 集，听众视角排序而非按原书五部分38章目录；建议线：①你脑里有两个操作系统 ②直觉的快与坑（启发法三兄弟）③过度自信与专家的错觉 ④前景理论：人是怕输的动物 ⑤两个自我打架+峰终定律 ⑥终极清单（集数按素材密度微调）
   - 依赖：第 1 步
3. **逐集讲稿** —— `output/《思考，快与慢》/02~NN-*.md`
   - 执行内容：每集结构=钩子开场→问题→一句话答案→故事/实验→概念拆解→讲者判断→落地清单；每集纯汉字 1500~2000，用 `re.findall(r'[\u4e00-\u9fff]', text)` 逐集核验，实测数字写进对应文件末尾
   - 依赖：第 2 步
4. **合并完整版** —— `output/《思考，快与慢》/99-完整版.md`
   - 执行内容：全部集数合并 + 终极清单（书中工具的操作化条目）
   - 依赖：第 3 步
5. **头条适配包** —— `output/《思考，快与慢》/toutiao/NN-*.md` + `toutiao/00-发布指南.md`
   - 执行内容：每集一个发布文件=标题≤30字+文首~100字摘要+正文+下集预告+话题标签建议（#读书 #思考快与慢 #认知）；发布指南写注册步骤、原创/AIGC勾选提示、日更节奏
   - 依赖：第 3 步
6. **发布指导** —— 对话内交付
   - 执行内容：指导用户注册头条号（手机号即可发文，提现才需实名）；第 1 集后台粘贴发布，读者端可见即闭环
   - 依赖：第 5 步 + 用户操作

## 4. 风险与备选

- 模式B保真风险 → 四档存疑清单 + 争议点标注；拿到合法文件可重跑模式A
- 头条 AIGC 内容规范 → 发布时按编辑器提示勾选"AI辅助生成"（如有该选项）
- 引文风险 → 观点全用转述，引号只框确有出处的句子；英文版不把中译文当作者原话
- 用户注册/发布遇阻 → 截图排查或 windows-mcp 辅助
