# 《思考，快与慢》分集大纲（示例）

> 本文件是 `/book-distill` Phase 2 的产出样例，用于展示「小A式」大纲长什么样：
> 不按原书目录走，按听众关心的问题重组；每集一个钩子标题、一个观点抓手。

## Phase 0 定位

- 书型：观点/理论类（认知心理学）
- 这本书回答的问题：人的大脑怎么做判断和决策？为什么我们总是"知道自己不该这么想，但还是这么想了"？
- 写给谁：所有以为自己很理性的人
- 读完改变什么：知道什么时候能信直觉、什么时候必须喊停
- 目标篇幅：9 集 ≈ 1万字

## 蒸馏要点（摘自 00-蒸馏笔记.md）

- 核心论点：人脑有两套系统——系统1（快、自动、直觉）和系统2（慢、费力、理性）；我们绝大多数判断都是系统1做的，它高效但带着系统性偏差
- 论证链：双系统框架 → 逐一展示偏差（锚定/可得性/代表性/损失厌恶/过度自信）→ 这些偏差不是偶然是结构性的 → 记忆自我还会骗你第二遍（峰终定律）
- 保留案例：琳达问题、非洲国家 anchor 实验、医院新生儿性别抽样、出租车司机双峰实验、结肠癌手术记忆实验

## 分集

| 集 | 钩子标题 | 讲什么 | 承接 |
|---|---|---|---|
| 01 | 你的脑子里住着两个"你"，而坏事都是那个快的干的 | 系统1/系统2框架；系统1省电但粗糙，系统2聪明但懒 | 开场立框架 |
| 02 | 你以为你在思考，其实大脑在偷懒 | 认知惰性 + WYSIATI（你看到的不是全部，但大脑假装是） | 为什么偏差是系统性的 |
| 03 | 商场标价9999，不是为了让你买 | 锚定效应：一个随机数字如何劫持你的判断 | 第一个具体偏差 |
| 04 | 为什么人人都觉得飞机比汽车危险？ | 可得性启发：想得起来的=容易发生的 | 媒体与恐惧的放大器 |
| 05 | 越像就越真？琳达问题骗了所有人 | 代表性启发 + 忽视基础概率 | 故事压过统计 |
| 06 | 丢100块的痛，要捡多少钱才补得回来？ | 损失厌恶 + 前景理论：人对得失不对称 | 最值钱的一个观点，展开讲透 |
| 07 | 专家预测不如猴子扔飞镖 | 过度自信 + 后见之明 + 规划谬误 | 对"权威"祛魅 |
| 08 | 记忆里的你，和经历中的你，不是同一个人 | 峰终定律 + 体验自我 vs 记忆自我 | 收束到"人到底要什么" |
| 大结局 | 终极清单：什么时候信直觉，什么时候必须喊停 | 全书一页纸：双系统适用边界 + 9个偏差的自查清单 | 抗遗忘锚点 |

## 备注

- 每集 1500~3000 字口语稿；06 是"主菜集"可以写到上限
- 模式 B（无原文）时，锚定实验的具体数字（如幸运转盘 10/65）需进存疑清单复核
